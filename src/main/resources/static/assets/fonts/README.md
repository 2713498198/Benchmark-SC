# Homepage title font

The homepage uses MiSans Bold, matching the typography of the Xiaomi MiMo
homepage. These two WOFF2 subsets are served locally; other text keeps the
site's existing font stack.

Source: https://mimo.xiaomi.com/

Original public font files:

- https://cdn.cnbj1.fds.api.mi-img.com/aife/mimo-blog-fe/doc_build/fonts/MiSans-Bold.latin.8f8152e1f40f.woff2
- https://cdn.cnbj1.fds.api.mi-img.com/aife/mimo-blog-fe/doc_build/fonts/MiSans-Bold.home.fa35542983d5.woff2

Font information and usage terms: https://hyperos.mi.com/font/

MiSans belongs to Xiaomi. No MiMo logos, page code, or illustrations are used.
