# LEA-128 四轮相关密钥不可能差分判定

附件 `attachments/lea128_4round_spec.md` 完整定义了本题使用的 LEA-128 轮函数、密钥扩展、字序和测试向量；[论文出处](https://eprint.iacr.org/2022/512) 仅作为来源背景，若表述存在差异，以形式化规范为准。

设两次加密使用相同明文 `P'=P`，主密钥满足

```text
K' xor K = (0x00000001, 0x00000000, 0x00000000, 0x00000000).
```

判断执行恰好 4 轮后，是否存在 `P` 与 `K` 使

```text
E_K^4(P) xor E_K'^4(P') =
(0x00000000, 0x00000000, 0x00000000, 0x00000000).
```

若存在，请给出可复核的明文和主密钥见证；若不存在，请给出精确的不可满足性证明。必须返回可直接执行的验证代码、机器可读结果和简洁结论，并说明代码如何同时约束两次密钥扩展和两次加密。随机抽样或只检查有限组密钥不能证明“不可能”。

请分别标明当前实例的判定、执行过的检查及支持结论的证据，并保留相应的模型、代码和实际运行记录。

判分器可读取工作目录 `verification.json`。提交 `schema`（固定字符串 `cbsc-fixed-result-v1`）、`task_id`（本目录的完整题号）、`rounds`、`input_xor`、`master_key_xor`、`output_xor`、`classification`（`possible` 或 `impossible`）及 `solver_result`（`sat` 或 `unsat`）。为核对两组结果，再把主密钥差分改为四字向量 (0, 1, 0, 0)，保持其余边界相同，以 `positive_control` 对象给出其 `master_key_xor` 与 `solver_result`；另以 `known_answer_ciphertext` 给出附件中 24 轮已知答案测试的四字密文。各字可写为无符号整数或以 `0x` 开头的十六进制字符串。判分器逐项与独立归档结果对照。完整字段匹配可取得固定实例的满答案分；当前发布版尚不支持验证提交者自己的 UNSAT 证明，完整交付在报告中单列。

发布版的固定实例验收会核对以下记录。提交目标、正对照及已知答案测试的条件与结果。记录核对通过记为 `release_check_status=passed`。原题的独立证明另列，现版不计入完整证明通过率。
