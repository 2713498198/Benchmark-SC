# Question 041. LBlock MILP 建模结果复核

## 问题描述

背景。固定条件如下：
- 对象：LBlock 指定结果 eleven round MILP row
- 任务类型：MILP 建模结果复核

公开实验记录。一个 11 轮 LBlock 相关密钥 active-S-box MILP 实例包含 `958` 个 0-1 变量和 `1144` 个连续变量，共有 `7250` 条约束。求解器证明的活跃 S-box 下界为 `10`，原实验记录的运行时间为 `43793` 秒。

任务。写脚本检查两个变量分量的合计值，把运行时间同时换算为小时，并输出一行结构化复核结果：轮数、两类变量数、总变量数、约束数、已证明的活跃 S-box 下界和原实验时间。说明变量数与约束数只描述该 MILP 编码规模，运行时间依赖原实验平台；不要从这一行推断未给出的 12 轮或更高轮结果。

## 交付要求

1. 返回可执行代码或可复核的形式化模型，形式可以是 Python、Sage、C/C++、MILP、SAT/SMT、Gurobi LP/MPS、验证脚本或等价程序。
2. 给出运行命令、关键输出和最终结论；最终结论必须直接回答题目要求的数值、YES/NO 判定、trail、概率/权重、表格项或证明边界。
3. 说明代码或模型如何对应本题固定条件，包括轮数、变体、bit/word 顺序、边界条件、目标函数或判定条件。
4. 对 solver 结果给出可信性解释：区分 `OPTIMAL`、`FEASIBLE`、`UNSAT/INFEASIBLE`、`TIME_LIMIT`、`UNKNOWN`，不要用不充分的 solver 状态过度声明。
5. 若未能完全求解，返回已经执行的代码、日志、当前最强边界、可行 witness 或反例，并明确说明未证明的部分。
