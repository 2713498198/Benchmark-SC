# Question 111. 32 位模加常数 RX 差分的精确计数

所有变量均为 32 位无符号整数，`ROL_k` 表示循环左移 `k` 位，加法按模 `2^32` 计算。对固定常数 `a`、输入 RX 差分 `delta` 和输出差分 `Delta`，定义

```text
F(x) = (((ROL_k(x) xor delta) + a) mod 2^32)
       xor ROL_k((x + a) mod 2^32).
```

附件 `attachments/rx_add_constant_instances.json` 给出三个固定实例。请实现精确计数程序，对每个实例求

```text
N = #{x in {0,...,2^32-1} : F(x) = Delta}.
```

报告每个实例的 `N`、约分后的精确概率 `N/2^32` 和 `-log2(N/2^32)`；当 `N=0` 时明确说明该转移不可能。算法必须给出精确结果而不是抽样估计，并保留足以核查旋转边界和两条模加进位链的验证证据。返回可执行代码和最终结果。
