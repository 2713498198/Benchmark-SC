# Question 120. SPEEDY-192 固定双 S-box 层差分特征的精确概率

附件 `attachments/speedy_joint_instance.json` 完整定义了一个 192 位状态上的固定差分特征。状态依次执行

```text
X1 = SB(X0)
X2 = SC(X1)
X3 = SB(X2)
X4 = SC(X3)
```

其中 `SB` 对 32 个 6 比特行分别应用附件中的 S-box，`SC` 按附件中的全局比特映射执行。附件固定了 `X0`、`X1` 和 `X4` 处的 XOR 差分。

请实现精确验证程序，计算该固定 characteristic 的真实概率。还应报告在错误地把两层 S-box 的局部转移视为相互独立时得到的 DDT 概率乘积，并用机器可核查的证据解释两个结果是否一致。概率必须是精确结果，不能用随机抽样代替；返回可直接执行的代码和最终结论。
