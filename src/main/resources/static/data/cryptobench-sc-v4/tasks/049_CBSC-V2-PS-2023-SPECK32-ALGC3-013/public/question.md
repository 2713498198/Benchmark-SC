# Question 049. SPECK32 差分攻击参数复核

## 问题描述

背景。固定条件如下：
- 对象：SPECK32/64 Algorithm C three trail row
- 任务类型：差分攻击参数复核

公开实例。Algorithm C 同时使用 Type-I 与 Type-II plaintext structures，并允许多个兼容 trails 共同贡献。对 SPECK32/64，给定 9 轮核心 differential、split `2+9+3`、3 条 trails、`nBIL=3`、`nFIL=3`，三条 trail 的总概率为 `p_hat=2^-28.42`。取 right-pair 系数 `mu=3` 时，数据量公式为

```text
D = mu / p_hat * 2 = mu * 2^(28.42+1).
```

该攻击模型报告约 66% 成功率、时间 `2^60.58`、内存 `2^36`。

任务。用脚本复核总概率的数值、数据复杂度指数及 split 总轮数，输出 algorithm、trail 数、`nBIL`、`nFIL`、总概率、成功率、split、数据、时间和内存。明确成功率及时间/内存是给定攻击模型的报告值，而脚本实际复核的是概率、轮数和复杂度表达式的一致性；不要把三条 trail 当成三次独立完整攻击。
