# Question 108. SKINNY-64/TK3 五轮 boomerang 中间概率精确计算

附件 `attachments/skinny64_boomerang_tables.json` 给出本题采用的 4 比特 S-box，以及 DDT、BCT、UBCT、LBCT 和 FBCT 五类连接表的精确定义。附件 `attachments/factor_graph.json` 给出一个固定五轮 boomerang 中部对应的 20 个局部因子和 21 个待求和差分变量；每个局部因子的概率等于相应连接表计数除以 16。

请实现一个精确计算程序，对所有 21 个变量求和，计算附件中因子乘积之和。直接枚举 `16^21` 个赋值不可行，应使用精确变量消元、因子图动态规划、张量收缩或等价方法，并避免浮点舍入改变最终结果。

请报告约分后的精确有理数、十进制概率和 `-log2(p)`，说明使用的求和方法及本题结论只对应给定的五轮中部，并提供可执行代码和机器可复核的计算证据。
