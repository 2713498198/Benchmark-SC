# Question 114. Midori64 五轮固定差分特征的弱密钥仿射条件

附件 `attachments/midori64_spec.json` 给出本题使用的 Midori64 轮函数、状态与密钥比特编号、轮常数及取消了首尾白化的建模边界；`attachments/trail_5r.json` 给出五轮每个 S-box 的输入和输出差分。

请建立精确的 SAT/SMT 或等价布尔模型，将每个 S-box 的具体成对值、线性层、轮常数以及交替使用的两个 64 比特密钥半部 (K_0,K_1) 同时纳入约束。在 128 比特主密钥空间上，求出所有能使该差分特征存在有效明文对的密钥所满足的完整仿射必要条件。

返回仿射包的维数和余维数、一组独立仿射方程（任意等价基均可）、不存在违反该仿射条件的有效密钥之求解证据，并报告按 S-box DDT 独立相乘的概率、有效密钥比例以及在有效密钥集上的条件概率。同时返回可执行代码和可复核的求解记录。
