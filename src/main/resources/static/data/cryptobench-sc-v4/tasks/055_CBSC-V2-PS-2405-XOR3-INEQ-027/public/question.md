# Question 055. Three XOR 门不可能转移约束验证

## 问题描述

背景。固定条件如下：
- 对象：Three input XOR impossible transition inequalities
- 任务类型：XOR 门不可能转移约束验证

任务。对三输入 XOR 门 D = A xor B xor C 的 activity-transition 模型，枚举所有 0/1 输入输出活动模式，找出奇偶性不可能转移，并构造对应线性不等式。报告 forbidden transitions 和 inequalities。
