# BAKSHEESH 7 轮积分与两轮密钥筛选结构审计

附件 `attachments/baksheesh_instance.json` 完整定义了 BAKSHEESH-128 的状态编号、S-box、置换、轮常数和密钥调度。考虑由全部 `2^14` 个明文组成的结构：输入位 `0..13` 遍历所有取值，其余 114 位固定但任意；同一结构中的明文使用同一未知主密钥。

请确定 7 轮后所有形如 `4i+3`（`0 <= i < 32`）的输出位中，哪些位具有与密钥及固定非活动位取值无关的平衡积分性质。随后把该性质向后扩展两轮，完成以下审计：

1. 推导从一个平衡位到下一轮三个可观测状态位 XOR 和的等价关系；

3. 判断重复使用独立明文结构进行筛选时，每个合并后的 16 比特子密钥组最少还会保留多少个不可区分候选，并给出该下界的 S-box 级原因。

返回可直接执行的验证代码、关键运行证据和最终结论。经验枚举可以作为交叉检查，但若声称性质对任意密钥和任意固定非活动位成立，还需给出 division property、完整符号模型或其他完备论证。
