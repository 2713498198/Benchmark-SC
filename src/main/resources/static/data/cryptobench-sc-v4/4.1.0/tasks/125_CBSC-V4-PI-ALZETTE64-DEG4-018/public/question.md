# Question 125. 4-core Alzette 指定输出位的精确代数次数审计

附件 `attachments/alzette_mp_instance.json` 完整定义了一个 64 位 Alzette 实例及其单项式传播规则。状态写成两个 32 位字 `(x,y)`；状态位编号 `0..31` 对应 `x` 的 MSB 到 LSB，`32..63` 对应 `y` 的 MSB 到 LSB。第 `j` 个 core 为

```text
s       = x + ROR_a(y) mod 2^32
x_next  = s xor 0xb7e15162
y_next  = y xor ROR_b(s)
```

四个 core 的 `(a,b)` 依次为 `(31,24)`、`(17,17)`、`(0,31)`、`(24,16)`。令 `f` 为第四个 core 后状态位 31 的布尔坐标函数。

审计候选输入单项式 `pi_u`：`u[20]=0`，其余 63 个输入指数均为 1。请精确计算从 `pi_u` 到 `f` 的单项式 hull 大小及其奇偶性，据此确定该单项式在 `f` 的 ANF 中是否出现，并给出 `f` 的精确代数次数。不得把“存在一条可达传播路径”直接当作 ANF 系数非零；必须处理全部传播路径的模 2 抵消。

返回可直接执行的验证代码、关键求解或计数证据，以及包含上下界理由的最终结论。
