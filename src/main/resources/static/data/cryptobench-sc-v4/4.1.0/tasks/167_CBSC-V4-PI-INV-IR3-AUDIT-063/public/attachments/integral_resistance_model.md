# 固定审计模型

## 1. 编码

- 密钥索引 `k` 取 `0..31`；本题只把它当作 5 比特变量的完整真值表索引。
- 输入和输出均取 `0..7`。整数 `x=4*x1+2*x2+x3`，坐标 1、2、3 分别是最高位、中间位、最低位。
- 对掩码 `u=u1u2u3`，输入单项式为 `x^u=x1^u1*x2^u2*x3^u3`。
- `E_k` 是 CSV 第 `k` 行给出的置换，`D_k=E_k^{-1}` 必须由程序逐行求逆。

## 2. ANF 系数函数

对方向 `F in {E,D}`、输出坐标 `i in {1,2,3}`，写成

```text
F_k^(i)(x) = XOR_{u in {0,1}^3} c_u^(i)(k) * x^u.
```

每个 `c_u^(i)` 是定义在全部 32 个密钥上的布尔函数。请由 8 点真值表执行 GF(2) Mobius 变换得到这些系数，不能把单个密钥下的 ANF 系数误当成最终判定对象。

## 3. 一阶积分抗性判据

只取 `u != 111` 的 21 个系数函数。常数函数不应被视为“依赖密钥”，因此把每个函数规范化为

```text
c_bar(k) = c(k) XOR c(0),  k=1..31.
```

将 21 个 `c_bar` 作为 GF(2) 上的列向量。该方向满足本题的广义一阶积分抗性，当且仅当这 21 列的秩为 21。若秩不足，零空间中的非零向量给出一组系数函数，其异或是常数；本题所给实例中该常数应由程序实际计算。

## 4. 从依赖关系得到直接积分见证

对每个输出坐标 `i`，把依赖关系中出现的单项式掩码组成 parity set `U_i`。对应的输入集合 `M_i` 由下式唯一确定：

```text
u in U_i  <=>  XOR_{x in M_i} x^u = 1.
```

若依赖异或得到常数 `b`，则必须直接检查全部 32 个密钥是否满足

```text
XOR_{i=1..3} XOR_{x in M_i} F_k^(i)(x) = b.
```

请输出 `U_i`、`M_i`、常数 `b` 和按 `k=0..31` 排列的 32 位复放向量。
