# TWINE 十五轮固定边界差分规范

## 1. 状态与编号

每轮输入写成两个八 nibble 向量

```text
L^r = (L^r_0,...,L^r_7),  R^r = (R^r_0,...,R^r_7).
```

一个八位十六进制串从左到右依次表示下标 `0,...,7`；例如 `c000ca00` 表示 `(c,0,0,0,c,a,0,0)`。所有量均为 XOR 差分。

## 2. S-box 与局部权重

TWINE 的四比特 S-box 为

```text
S = [c,0,f,a,2,b,9,5,8,3,d,7,1,e,6,4].
```

定义

```text
DDT[dx,dy] = |{x in {0,...,15}: S(x) xor S(x xor dx) = dy}|.
```

局部转移只有在 `DDT[dx,dy] > 0` 时才可用，其权重为

```text
w(dx,dy) = -log2(DDT[dx,dy] / 16).
```

一轮的权重是八个局部 S-box 权重之和，十五轮总权重是各轮权重之和。

## 3. 轮函数

令 `U^r_i` 是 `L^r_i` 经过 S-box 后的输出差分。对 `r=1,...,14`，下一轮状态由下式唯一确定：

```text
L^(r+1)[P_L[i]] = U^r_i xor R^r_i
R^(r+1)[P_R[i]] = L^r_i
```

其中

```text
P_L = [0,2,6,4,3,1,5,7]
P_R = [2,0,3,1,6,4,7,5].
```

第 15 轮不再执行上述 permutation，密文侧输出差分定义为

```text
C_L = L^15
C_R[i] = R^15_i xor U^15_i.
```

轮密钥 XOR 不改变普通 XOR 差分，因此不出现在差分传播式中。

## 4. 固定边界

固定第一轮输入为

```text
L^1 = 00000000
R^1 = c000ca00
```

固定第十五轮无 permutation 输出为

```text
C_L = 00700070
C_R = a09a00c0.
```

优化目标是在严格满足上述语义和边界的全部十五轮单条差分特征中最小化总权重。
