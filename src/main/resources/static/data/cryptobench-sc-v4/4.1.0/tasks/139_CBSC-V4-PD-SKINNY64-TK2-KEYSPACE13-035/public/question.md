# SKINNY-64-128 十三轮相关密钥差分特征的密钥依赖审计

附件 `attachments/skinny64_tk2_trail_instance.json` 给出了本题采用的 SKINNY-64-128/TK2 轮函数、tweakey 调度、相关 tweakey 差分，以及从第 0 轮输入到第 13 轮输出的完整差分边界。

请编写可执行程序，精确审计该差分特征在真实 tweakey 调度下的概率。程序需要验证全部局部 S-box 转移，识别跨轮共享状态值和轮 tweakey 所形成的依赖，并据此给出：按独立轮假设计算的名义概率、允许该特征成立的主 tweakey 比例、在有效主 tweakey 上的条件概率，以及对全部主 tweakey 平均后的概率。

同时给出可复核的依赖证据，例如受约束的轮/单元、允许的有效轮 tweakey 值集合，或语义等价的精确计数/不可满足证书；并说明该特征是对所有 tweakey 有效、完全不可能，还是仅对部分 tweakey 有效。

返回可直接执行的代码、机器可读结果和最终结论。
