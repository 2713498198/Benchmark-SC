# GIFT 4 位 S-box 的 LAT 最小闭包完备枚举

附件 `attachments/gift_lat_closure_spec.md` 给出了 GIFT 4 位 S-box、线性逼近表支持集以及单个整数不等式闭包的精确定义。

请计算该 LAT 支持集的全部最小单不等式闭包。报告 LAT 支持集大小、最小闭包总数、闭包大小分布及最小/最大闭包大小，并按附件规定的规范掩码编码输出完整闭包族及其 SHA-256。完整闭包族必须留下机器可读产物，不能只报告数量或摘要。

同时给出可直接执行的分析代码和简洁审计报告，说明如何确认每个结果都包含 LAT 支持集、可由一个整数线性不等式表示、彼此不重复且互不严格包含，并说明为何没有遗漏其他最小闭包。随机搜索、仅生成部分候选或没有完备性依据的启发式结果不构成完整答案。
