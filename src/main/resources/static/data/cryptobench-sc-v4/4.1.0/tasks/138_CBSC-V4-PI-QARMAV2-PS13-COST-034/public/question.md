# QARMAv2-64-128 十三轮积分密钥恢复的复杂度审计

附件 `attachments/attack_cost_instance.json` 给出一个 13 轮 QARMAv2-64-128 积分密钥恢复实例的两条 partial-sum 路径、单位换算和总时间公式。

请编写可执行程序完成以下审计：

1. 由每条 partial-sum 路径的逐步指数重建其精确 MA 操作数及 `log2` 复杂度。
2. 在 `s=1,...,16` 上按附件的括号范围和单位换算，以 ENC 为单位计算总时间。
3. 找出使总时间严格小于 `2^112 ENC` 所需的最小 `s`，并给出该 `s` 下的时间、数据和存储复杂度。
4. 另行报告 `s=1,...,16` 中使总时间最小的 `s`，并说明它是否与“达到安全边界的最小 `s`”相同。

返回可直接执行的代码、机器可读结果和最终结论。
