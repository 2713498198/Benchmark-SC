# CRAFT 两轮列 superbox 的完美线性弱密钥分类

附件 `attachments/craft_superbox_spec.md` 精确定义了一个 CRAFT 两轮列 superbox、掩码内积和弱密钥判据。

对固定输出掩码 `beta = 0xb200`，完整分类所有使该映射存在非平凡完美线性近似的 16 比特中间密钥。报告弱密钥集合的精确表示和大小，并对集合中的每类密钥给出对应输入掩码 `alpha`、常数位 `c` 及相关系数；同时给出两轮可分性条件所允许的全部输出掩码空间。结论必须排除集合外的密钥，而不能只展示若干成功样例。

必须返回可直接执行的精确分析代码、机器可读结果和简洁审计报告。随机抽样、仅测试少数密钥或只给出一个弱密钥不构成完整答案。
