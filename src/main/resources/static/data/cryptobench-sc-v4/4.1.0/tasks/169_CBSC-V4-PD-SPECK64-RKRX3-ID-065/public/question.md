# SPECK-64/64 三轮相关密钥 RX 不可能差分判定

考虑只含三轮轮函数的 SPECK-64/64。状态和主密钥均由两个 32 位字组成，分别记为 `(x,y)` 和 `(k,l)`。所有加法均模 `2^32`，`ROL_j`、`ROR_j` 表示 32 位循环左移、循环右移；最低有效位编号为 0。

三轮加密使用轮密钥 `k_0,k_1,k_2`：

```text
k_0 = k,  l_0 = l
l_{i+1} = (ROR_8(l_i) + k_i) xor i       (i = 0,1)
k_{i+1} = ROL_3(k_i) xor l_{i+1}

x_{i+1} = (ROR_8(x_i) + y_i) xor k_i     (i = 0,1,2)
y_{i+1} = ROL_3(y_i) xor x_{i+1}
```

对两个 32 位字 `z,z'`，旋转量为 1 的 RX 差分定义为

```text
delta_z = z' xor ROL_1(z),
```

并逐字应用于状态和主密钥。两次执行的主密钥满足固定关系

```text
(delta_k, delta_l) = (0x00000000, 0x00000080).
```

请精确判定是否存在两组明文和满足上述关系的两组主密钥，使三轮加密满足

```text
输入 RX 差分：(delta_x0, delta_y0) = (0x00000000, 0x00000001)
输出 RX 差分：(delta_x3, delta_y3) = (0x00008000, 0x00000000).
```

返回可直接执行的验证代码、求解器的精确状态，并说明该状态在相关密钥 RX 差分语义下意味着什么。为排除边界映射错误或模型恒定返回不可满足，请用同一模型检查下面的相邻对照实例：

```text
输入 RX 差分：(delta_x0, delta_y0) = (0x80000000, 0x00000000)
输出 RX 差分：(delta_x3, delta_y3) = (0x00008000, 0x00000000)
主密钥 RX 差分保持不变。
```

若对照实例可满足，请给出足以独立复放的完整见证。允许使用 SAT/SMT、精确 MILP、BDD、位级符号执行或其他完备方法；随机试验和有限抽样不能证明不可达。
