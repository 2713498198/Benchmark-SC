# CRAFT 七轮中间回旋矩阵的精确条目复放

附件 `attachments/craft_r7_matrix_definition.md` 完整定义了 CRAFT 4 比特 S-box、所需局部连接表、分块收缩公式和归一化方式；`attachments/reference_paper.pdf` 仅作为背景资料，发生表述差异时以前一份形式化定义为准。

请精确计算四维矩阵 `R7[a1,a2,h1,h2]` 的以下四个条目：

- `R7[a,a,a,a]`
- `R7[a,a,5,5]`
- `R7[5,5,5,5]`
- `R7[a,5,a,5]`

对每个条目报告归一化前的整数分子、约分后的精确概率和 `log2(probability)`；概率为零时明确报告其为零。说明非零条目计算所采用的精确收缩方法，并解释混合条目是否存在兼容赋值。

必须返回可直接执行的验证代码、机器可读结果和简洁结论。不得以随机抽样或仅保留浮点数的计算替代精确整数计数。
