# SKINNY-128 S-box 差分 MILP 模型审计

附件 `attachments/skinny128_sbox.json` 给出 SKINNY-128 的 8 比特 S-box，`attachments/corrupted_model.txt` 给出一个由 177 条整数线性不等式组成的差分传播模型。该模型原本应精确描述 S-box DDT 中所有非零传播，但传输过程中恰有两个整数被分别改动了 1；没有增删或重排不等式。

对输入差分 `alpha` 和输出差分 `beta`，令 `z = (alpha << 8) | beta`，并令 `x_j = (z >> j) & 1`。模型每行依次为 `a_0,...,a_15,b`，语义为

```text
a_0*x_0 + ... + a_15*x_15 + b >= 0.
```

请实现一个可直接执行的审计程序，独立生成 DDT 非零支持集，检查损坏模型在全部 65,536 个差分对上的行为。报告损坏模型的接受点数以及全部错误接受和错误拒绝的差分对。在“恰好修改两个整数、每处改变量为 `+1` 或 `-1`”的范围内，枚举所有能使模型与 DDT 支持集完全一致的语义修复；若原始改动位置不能由这些条件唯一确定，必须明确说明。任选一组语义修复输出修复模型，并再次穷举证明它与 DDT 支持集完全一致。

最后，对你实际输出的修复模型计算以下边界指标：本实例的边界集合固定为 DDT 非零支持集；一个边界点被某条不等式覆盖，当且仅当它使该不等式恰好取零。报告每个边界点上的取零不等式数的最小值、至少被一条不等式覆盖的边界点数及覆盖率。

返回可直接执行的代码、修复后的模型和审计报告。不能用引用现成结论代替对 DDT 与不等式的完整复放。
