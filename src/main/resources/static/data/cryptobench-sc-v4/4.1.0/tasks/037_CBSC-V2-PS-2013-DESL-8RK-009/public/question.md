# Question 037. DESL 相关密钥差分特征计算

## 问题描述

背景。固定条件如下：
- 对象：DESL eight round related key characteristic
- 任务类型：相关密钥差分特征计算

公开研究记录。一次 DESL 相关密钥 MILP 搜索得到一条 8 轮 characteristic，累积有效权重为 `34.78`；原实验在当时的 PC 上用时少于 10 分钟。该模型若不增加非平凡条件，会在 5 秒内找到“无活跃 S-box、概率为 1”的退化相关密钥 characteristic。研究中采用的排除条件是：整个 characteristic 至少有一个活跃 S-box。

任务。请写脚本或形式化检查器复核 `weight=34.78` 与 `probability=2^-34.78` 的换算，并说明为何“至少一个活跃 S-box”只能排除上述平凡解，而不能单独证明给定 8 轮 characteristic 全局最优。报告有效权重、概率近似值、原实验搜索时间和 anti-trivial condition；必须把历史运行时间与本次实际运行时间分开。
