# SKINNY-64-64 十轮固定集合的精确积分复放

附件 `attachments/skinny64_tk1_integral.json` 完整定义了 10 轮 SKINNY-64-64 的状态顺序、轮函数、主 tweakey 调度和两个固定实验实例。

对每个实例，让明文单元 `P[5]、P[7]、P[10]、P[13]` 与主 tweakey 单元 `TK[5]` 相互独立地遍历 `0..15`，其余单元固定为附件给出的基值。对集合中的每个 `(P,TK)` 执行完整 10 轮加密，记输出为 `X10`。

请对两个实例分别计算：

- 实际枚举的不同 `(P,TK)` 数量；
- 16 个输出单元各自对全集取 XOR 后得到的完整 nibble 向量；
- `X10[5] xor X10[13]` 在全集上的 16 项值分布，以及这些值的总 XOR；
- 该输出组合是否构成平衡积分性质。

必须返回可直接执行的验证代码、机器可读结果和简洁结论。随机抽样或只传播活动模式不能替代完整集合计算。
