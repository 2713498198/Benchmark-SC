# LBlock 十六轮相关密钥零到零差分判定

附件 `attachments/lblock_instance.json` 给出 LBlock 的十个 4 比特 S 盒、轮函数中的字位置、S 盒顺序和两组完整轮测试向量。所有整数均按通常的十六进制大端书写；对一个整数内部的比特编号，bit 0 是最低有效位。

将 64 比特状态写成 `P = L_0 || R_0`，其中 `L_0` 是高 32 比特。对 `r = 0,...,15`，令 `sk_r = K_r[79:48]`，并执行

```text
L_{r+1} = F(L_r xor sk_r) xor ROL_8(R_r)
R_{r+1} = L_r.
```

`F` 先把 32 比特输入按从最高有效位到最低有效位分成 8 个 nibble。附件中的 `word_positions_from_msb` 指定依次读取的输入 nibble，`sbox_order` 指定对应 S 盒；八个 S 盒输出按该顺序从最高有效位到最低有效位拼接。16 轮输出为 `C = R_16 || L_16`。

80 比特密钥状态按 `K_r = k_79...k_0` 编号。由 `K_r` 生成 `K_{r+1}` 时，先循环左移 29 位，再分别对最高和次高 nibble 应用 `S9` 与 `S8`，最后按整数运算异或 `((r+1) << 46)`。轮常量在两次相关密钥执行的 XOR 差分中抵消，但实现完整加密时仍应保留。

固定以下 16 轮相关密钥差分实例：

```text
Delta P = 0x0000000000000000
Delta C = 0x0000000000000000
Delta K = 0x00000000000000000040
```

请判定是否存在满足该边界的 16 轮差分特征，并据此判断它是否为相关密钥不可能差分。结论必须覆盖非线性密钥调度产生的全部可行子密钥差分，不能只检查一个具体主密钥、一个具体明文或一种 S 盒输出。返回可直接执行的精确验证代码、机器可读的判定结果和足以复核结论完备性的证明证据。允许使用完整 DDT 可行性模型、SAT/SMT、约束传播、完备分支证明或其他等价的严格方法；随机抽样和求解超时不能作为不可能性的证明。
