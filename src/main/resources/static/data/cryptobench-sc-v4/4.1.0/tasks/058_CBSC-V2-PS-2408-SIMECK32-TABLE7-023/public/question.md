# Question 058. Simeck32 差分线性配置结果复核

## 问题描述

背景。固定条件如下：
- 对象：Simeck32 指定结果 first comparison row
- 任务类型：差分线性配置结果复核

公开实验记录。一个 12 轮 Simeck32 differential-linear 实例使用 split `(Rd,Rm,Rl)=(5,2,5)`。中心单条 DL trail 的绝对相关性 `CorT=2^-16.00`；枚举相同输入差分和输出 mask 下的兼容 differential/linear trails，并用有符号 DLCT contribution 聚合后，得到 `CorD=2^-9.00`。记录中的 gap 定义为 `(CorD-CorT)/CorT*100%`。

任务。用脚本复核 split 总轮数、两个相关性的数值、`CorD/CorT` 倍率和 gap 百分比。报告 configuration、`CorT` 与 `CorD`，并解释为什么 `CorD` 是固定端点下的聚合 distinguisher correlation，而不是把单条 trail 的指数直接改写。明确这些给定记录不构成对全部 12 轮 Simeck32 distinguishers 的全局最优性证明。
