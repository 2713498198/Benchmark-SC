# 四分支素域置换尾部轮数的总次数上界审计

令 `p = 2^31 - 1`。考虑一个四分支素域置换的次数传播模型。模型中的所有普通整数变量取值于 `[0,p-1]`，每次调用下列关系时使用相互独立的新变量。

对输入 `u`、输出 `v0,v1`，复制关系 `Copy(u;v0,v1)` 引入二元变量 `c` 并满足

```text
c*(p-1) + u = v0 + v1,
0 <= v0 + v1 - c*p <= p-1.
```

对输入 `u`、输出 `v`，平方关系 `Square(u;v)` 引入二元变量 `c` 并满足

```text
c*(p-1) + u = 2*v,
v <= u*(p-1),
u <= v*(p-1).
```

普通加法关系为 `Add(u0,u1;v): v=u0+u1`；常数加法关系为 `Const(u;v): v>=u`。所有关系的输入和输出仍受普通变量的 `[0,p-1]` 域约束。

一轮 `Round(u0,u1,u2,u3) -> (v0,v1,v2,v3)` 使用中间变量 `e0,...,e17`，按以下顺序连接：

```text
Copy(u0; v2,e0)       Copy(u1; v3,e1)
Const(e1;e2)          Copy(e2;e3,e4)
Square(e3;e5)         Add(e0,e5;e6)
Copy(e6;e7,e8)        Add(e4,e7;e9)
Copy(e9;e10,e11)      Add(e8,e10;e12)
Const(e11;e13)        Copy(e13;e14,e15)
Square(e14;e16)       Add(e12,e16;e17)
Add(e17,u3;v1)        Add(e15,u2;v0)
```

一个 `Step` 先对四个输入分别施加一次 `Const`，再连续执行四个 `Round`。对总轮数 `r`，令 `(q,s)=divmod(r,4)`：从输入状态开始执行 `q` 个完整 `Step`，随后再对四个分支分别施加一次 `Const`，最后执行 `s` 个 `Round`。

请编写可直接执行的精确优化程序。对每个 `r=30,31,...,35` 和每个输出坐标 `j=0,1,2,3`，把最终状态固定为第 `j` 个位置为 1、其余位置为 0，并最大化初始四个变量之和。报告按坐标顺序排列的六个四元最优值向量、理论最大总次数 `4*(p-1)-1`、首次有任一坐标达到该最大值的轮数及坐标、首次四个坐标全部达到该最大值的轮数。每个坐标实例都必须给出求解状态、目标值、最优界和一个初始状态见证；只有目标值等于最优界且求解状态为 `OPTIMAL` 才可宣称最优。
