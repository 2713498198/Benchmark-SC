# SKINNY-128 S-box 的两轮不可能回旋局部表审计

附件 `attachments/skinny128_iulbct_spec.md` 给出了固定 8 位 S-box、DDT、GBCT、iUBCT 和 iLBCT 的精确定义。

请完整计算定义域 `0 <= alpha,beta < 256` 上 iUBCT 与 iLBCT 的全部零元素。分别报告两个零集合的大小、交集和并集大小，并按附件规定的规范编码给出两个零集合及其并集的 SHA-256。完整零集合必须保存为机器可读产物，不能只报告数量或摘要。

同时给出可直接执行的分析代码和简洁审计报告，说明如何穷尽全部中间差分、如何检查边界性质和逆 S-box 对偶性质，以及每类零元素对两轮不可能回旋传播能够证明什么、不能证明什么。
