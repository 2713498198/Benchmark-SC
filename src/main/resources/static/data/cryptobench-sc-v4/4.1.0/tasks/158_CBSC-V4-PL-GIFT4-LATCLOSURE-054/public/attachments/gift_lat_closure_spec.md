# GIFT S-box、LAT 与最小单不等式闭包

## S-box 与 LAT

使用以下 4 位 S-box，数组下标和数组值均按普通无符号整数解释：

```text
S = [0x1, 0xa, 0x4, 0xc, 0x6, 0xf, 0x3, 0x9,
     0x2, 0xd, 0xb, 0x7, 0x5, 0x0, 0x8, 0xe]
```

令 `parity(z)` 为整数 `z` 的二进制表示中 1 的个数模 2。对输入掩码 `a` 和输出掩码 `b`，其中 `0 <= a,b < 16`，定义

```text
LAT[a,b] = sum_{x=0}^{15} (-1)^(parity(a & x) xor parity(b & S[x])).
```

将一对掩码编码为

```text
u = (a << 4) | b.
```

本题的目标支持集为

```text
P = { u in [0,256) : LAT[a,b] != 0 }.
```

## 单不等式闭包

把 `u` 写成 8 位向量 `(u_0,...,u_7)`，其中

```text
u_i = (u >> i) & 1
```

且 `u_0` 是最低有效位。任取整数系数 `c_0,...,c_7,d`，定义一个阈值集合

```text
C(c,d) = { u in [0,256) : sum_{i=0}^{7} c_i*u_i + d >= 0 }.
```

若 `P` 是 `C(c,d)` 的子集，则称 `C(c,d)` 为 `P` 的一个单不等式闭包。若不存在另一个单不等式闭包 `D` 满足

```text
P subseteq D proper_subset C(c,d),
```

则称 `C(c,d)` 为最小单不等式闭包。不同系数可能表示同一个闭包；本题按集合本身去重，不按系数向量去重。

## 规范编码

对闭包 `C` 定义 256 位整数

```text
mask(C) = sum_{u in C} 2^u.
```

把 `mask(C)` 写成恰好 64 个小写十六进制数字，不带 `0x` 前缀；最左侧是最高有效十六进制位，整数的第 `u` 位表示点 `u` 是否属于 `C`。将所有闭包掩码按这 64 个字符的字典序升序排列，每行一个，使用 LF 换行并在最后一行后保留换行。完整文件字节的 SHA-256 即为闭包族摘要。

为便于复核，LAT 支持集摘要采用如下独立规则：将 `P` 中的整数按升序写成十进制，以单个空格连接，并在末尾追加一个 LF；对这些 ASCII 字节计算 SHA-256。
