# Speck32 十二轮 MiF 动态计数攻击复核

附件 `attachments/speck32_mif_weight_distribution.txt` 是一个 12 轮 Speck32/64 差分密钥恢复实例的冻结采样数据。攻击采用 `1+8+1+2` 轮划分，需要恢复 64 位主密钥，中间过滤簇大小为 12。附件的第 2 行依次为采样明文对数和采样 trail 数，第 3 行依次为簇大小与单个明文对产生有效 trail 的效率指数 `log2(q)=-27.299560`。随后 64 行对应密钥递归深度 1至64；每行第 `w+1` 个数是局部 trail 权重为 `w` 的样本数。

请编写可执行程序，使用这些冻结样本估计成功率至少为 63.212% 的多 trail 动态计数攻击，并在计数阈值 `c=1,...,8` 中找出总时间最小的方案。计算采用以下统一约定：

- 对每个深度 `d`，令 `q_d` 为该行直方图下 `2^-w` 的样本平均，并定义 `q_0=1`。
- 若处理的 trail 数为 `n_trails`，令 `eta_d=n_trails*q_d`。在 `2^d` 个候选子密钥中独立投放 trail-key 对，仅保留至少被 `c` 条 trail 支持的子密钥时，深度 `d` 的期望 trail-key 对数为
  `v_d = 2^d*eta_d*(1-exp(-eta_d)*sum_{i=0}^{c-2}(eta_d^i/i!))`；对 `c=1`，括号内按 1 处理。
- 令 `c'/q` 为所需明文对数，其中 `c'` 由
  `1-exp(-c')*sum_{i=0}^{c-1}(c'^i/i!)=0.63212`
  确定。数据复杂度 `D` 按选择明文个数计，即明文对数的两倍。
- `n_trails=(c'/q)*(sampled_trails/sampled_pairs)`。枚举复杂度为 `T_enum=(2/12)*sum_{d=0}^{63}v_d`，最终候选密钥试解复杂度为 `T_trials=(8/12)*v_64`，`T_cnt=T_enum+T_trials`。
- 对 16 位字长，通用 MiF 复杂度为
  `T_generic=(c'/q)*2^12.1*(1/(5*12)+12*11/(2^16*5*12))`；
  两轮简化 MiF 复杂度为 `T_simple=(c'/q)*12*4/12`。取 `T_mif=min(T_generic,T_simple)`，且 `T_att=T_cnt+T_mif`。所有时间均以一次完整 12 轮加密为单位。

给出可复核的 `c=1,...,8` 计算结果、最优阈值及其 `D`/`T_enum`/`T_trials`/`T_cnt`/`T_mif`/`T_att` 二进制对数，并说明为什么仅比较最终候选数或 `T_trials` 会得到错误的阈值选择。返回可直接执行的代码、机器可读结果和最终结论。
