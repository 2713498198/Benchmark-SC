# 10 比特 CA-Feistel S-box 的差分、线性与回旋审计

在 `0..1023` 上构造置换 `S`。整数按小端位编号，`bit 0` 是最低位；低 5 位为左半 `L`，高 5 位为右半 `R`。

对 5 比特环 `r`，定义元胞自动机 `CA(r)`。其第 `i` 个输出位读取

```text
(r[i-2], r[i-1], r[i], r[i+1], r[i+2])
```

其中下标模 5，以上述顺序组成一个 5 比特整数，最左位权为 16、最右位权为 1。令 `q = 1438886595`，该输出位等于 `(q >> neighborhood) & 1`。定义 Feistel 轮

```text
F(L,R) = (R, L xor CA(R)).
```

再定义全 10 比特仿射置换 `A[a,b](x) = (a*x+b) mod 1024`。从输入 `x` 开始，依次执行

```text
A[5,3], F^4, A[7,11], F^3, A[13,17], F
```

得到 `S(x)`。

请编写可直接执行的程序，重建完整 1024 项 S-box，并完成以下精确审计。记 `parity(z)` 为 `z` 的比特奇偶和，且

```text
f_beta(x) = parity(beta & S(x)),  beta != 0,
W(alpha,beta) = sum_x (-1)^(parity(alpha & x) xor f_beta(x)).
```

报告所有非零 `beta` 对应分量函数的 ANF 次数最小值、最大值、次数直方图及达到最小次数的全部 `beta`；报告向量非线性度

```text
min_beta [512 - max_alpha |W(alpha,beta)|/2]
```

以及达到该值的全部输出掩码。在线性部分，报告 `M = max |W(alpha,beta)|` 及全部带符号最大项 `(alpha,beta,W)`，并分别给出 `C2=(M/1024)^2` 和 `LAP*=4*C2`。

差分分布表定义为

```text
DDT[a,b] = #{x : S(x) xor S(x xor a) = b}.
```

在 `a != 0` 上报告差分均匀度、最大差分概率及全部最大项 `(a,b)`。由逆置换定义

```text
BCT[a,b] = #{x : S^-1(S(x) xor b) xor S^-1(S(x xor a) xor b) = a}.
```

在 `a != 0, b != 0` 上报告回旋均匀度及全部最大项 `(a,b)`。结果必须来自完整定义域的精确计算，而非抽样。返回可执行代码、包含完整 S-box 与上述结果的机器可读文件，以及最终报告。
