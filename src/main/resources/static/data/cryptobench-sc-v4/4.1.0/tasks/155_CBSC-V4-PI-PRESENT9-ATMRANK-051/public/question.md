请审计“合并空间维数为 470，去除 `B` 后为 22 维，其中 14 维属于线性等价关系、剩余 8 维为广义关系”这一结论是否被附件数据支持。报告去重候选数、`T`、`B`、`L` 的精确 GF(2) 秩及三个商空间维数，并给出足以机器核验的非平凡线性依赖证书。

必须返回可直接执行的审计代码、机器可读结果和简洁结论。仅统计候选条数、使用实数近似秩、执行随机抽样，或只复述待审计数字，均不构成完整答案。
