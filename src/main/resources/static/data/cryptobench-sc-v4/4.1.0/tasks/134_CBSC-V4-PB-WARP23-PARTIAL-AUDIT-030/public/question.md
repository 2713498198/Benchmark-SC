# WARP 23 轮部分 boomerang 特征审计

附件 `attachments/candidates.json` 给出 WARP-128 的 4 比特 S-box、分支置换以及四份 23 轮部分 boomerang 特征候选 `c0` 至 `c3`。附件 `attachments/semantics.md` 给出状态传播、自由值、局部连接表和因子分类的完整语义。每份候选的随附元数据均声称其总权重为 140，但该数值未经验证。

请实现一个可直接执行的审计程序，从 S-box 真值表独立生成 DDT、FBCT、FBDT 和 FBET。对每份候选完成以下审计：

1. 检查所有不含自由值的 WARP 轮传播等式，报告实际检查的等式数和全部违反项。
2. 仅根据六个 activity/free 标志推导每个局部因子的类型，并逐项用连接表的原始计数复算其精确概率。
3. 报告各因子类型的数量、局部权重直方图、精确总概率和总权重，并判断随附的权重 140 是否正确。
4. 报告每份候选的上部输入差分和下部输出差分。差分按附件数组从索引 0 到 31 直接拼接为 32 个十六进制半字节，不做额外字节序反转。

审计程序必须保存足以复核每个非平凡局部因子的记录，至少包含轮号、S-box 位置、因子类型、参数、原始计数和局部权重。不能把元数据中的权重当作输入，也不能用引用现成结论代替对四份候选的完整复放。返回可执行代码和审计报告。
