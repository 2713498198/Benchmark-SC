# Question 116. Simeck64 十七轮边界簇的不可能差分判定

考虑只保留差分传播所需部分的 Simeck64 轮函数。状态为两个 32 位字 `(L_r, R_r)`，比特从最低位开始编号为 `0,...,31`，所有下标均模 32。`ROL_j(X)` 的输出比特 `i` 等于 `X[(i+j) mod 32]`。一轮定义为

```text
R_{r+1} = L_r
L_{r+1} = R_r xor (L_r & ROL_5(L_r)) xor ROL_1(L_r).
```

轮密钥在 XOR 差分中抵消，因此不写入上述轮函数。用 `0`、`1` 和 `*` 描述一个差分边界，其中每个 `*` 都是可独立取 `0` 或 `1` 的比特。固定以下 17 轮边界簇：

```text
输入差分（r = 0）
  L_0：bit 31 为 *，其余位为 0
  R_0：bit 2 为 1，bits 26、30、31 为 *，其余位为 0

输出差分（r = 17）
  L_17：bit 31 为 *，其余位为 0
  R_17：所有位均为 0
```

密码分析中只统计输入差分和输出差分都非零的具体边界对。请判断该边界簇中的所有非平凡具体边界对是否都是 17 轮不可能差分，并给出其准确数量。返回可执行的精确验证代码和可核查的证明证据；同时说明普通的上下传播直接冲突是否足够，若使用信息合并或间接传播，请给出合并位置和在上述编号约定下最早得到的冲突。允许使用 SAT/SMT、约束传播、完备枚举或其他等价的精确方法。
