# WARP-128 十一轮实例语义

## 状态与字符串顺序

- 状态和主密钥都表示为 32 个 4 比特半字节数组，索引为 `0..31`。
- 32 位十六进制字符串的第 `i` 个字符就是数组索引 `i`，不进行字节序或半字节序反转。
- 因而本题输入差分和输出掩码均只在索引 `15` 取值 `0x2`，其余索引均为零。

## 轮函数

对轮号 `r=0..10`，设轮输入为 `state[0..31]`，主密钥为 `key[0..31]`：

1. 对 `i=0..15` 计算 `left[i] = SBOX[state[2*i]] XOR key[(r mod 2)*16+i]`。
2. 对 `i=0..15` 更新 `state[2*i+1] = state[2*i+1] XOR left[i]`；偶数位置保持不变。
3. 更新 `state[1] = state[1] XOR RC0[r]` 和 `state[3] = state[3] XOR RC1[r]`。
4. 置 `new_state[PERM[j]] = state[j]`，其中 `j=0..31`，然后以 `new_state` 进入下一轮。

11 轮均执行上述置换。两个相关实验副本使用同一个任意主密钥。

## 有符号差分线性相关

设 `E_k` 为上述 11 轮映射，`Delta` 为附件给出的输入差分，`lambda` 为输出线性掩码。内积是所有被掩码选中比特乘积的异或和。本题相关定义为

```text
C_k(Delta, lambda)
  = 2^-128 * sum_x (-1)^(<lambda,E_k(x)> XOR <lambda,E_k(x XOR Delta)>).
```

“对全部明文和全部密钥成立”是指需要判断上述奇偶指数是否对每个 `x` 和每个 `k` 都相同，而不是只对某个固定密钥或随机样本成立。

## 局部 DLCT

对附件 S-box `S`，未归一化 DLCT 定义为

```text
DLCT(a,b) = # {x : <b,S(x)> XOR <b,S(x XOR a)> = 0}
          - # {x : <b,S(x)> XOR <b,S(x XOR a)> = 1}.
```

归一化有符号相关为 `DLCT(a,b)/16`。
