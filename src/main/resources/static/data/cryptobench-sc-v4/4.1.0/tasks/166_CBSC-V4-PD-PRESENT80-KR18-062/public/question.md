# PRESENT-80 十八轮差分攻击的密钥恢复策略审计

附件 `attachments/present80_key_recovery_model.md` 和 `attachments/present80_2plus2_instance.txt` 完整定义了固定的 PRESENT-80 分析实例、位序、差分边界、线性化轮密钥关系及成本模型。

请实现一个可执行分析程序，为该十四轮差分区分器前接两轮、后接两轮后的十八轮实例构造完整的密钥恢复策略。程序应从附件中的原语与差分约束出发，计算输入/输出差分空间维数、进入密钥恢复的候选对数量、预筛选效果、所有活动 S-box 的覆盖情况，以及策略的在线时间、离线预计算和内存复杂度；随后判断该策略是否达到模型允许的最小单位对成本，并据此判断密钥恢复复杂度是否低于穷举 80 比特密钥。

返回可直接执行的代码、足以复放活动 S-box 覆盖与成本计算的机器可读策略证据，以及简洁的密码分析结论。不得只引用最终复杂度、把区分器概率当作密钥恢复复杂度，或省略对完整策略覆盖和最优性下界的核验。
