`S` 是一个双射，`S^{-1}` 表示其逆置换。所有加法均为按位异或。

## DDT 与 GBCT

对 `alpha, alpha_prime, beta, beta_prime` 定义

```text
DDT(alpha, alpha_prime)
  = #{x : S(x) xor S(x xor alpha) = alpha_prime}.

GBCT(alpha, alpha_prime; beta, beta_prime)
  = #{x : S^{-1}(S(x) xor beta)
           xor S^{-1}(S(x xor alpha) xor beta_prime)
           = alpha_prime}.
```

## iUBCT 与 iLBCT

```text
iUBCT(alpha, beta)
  = #{(a1,a1') :
        DDT(alpha,a1) > 0,
        DDT(alpha,a1') > 0,
        GBCT(a1,a1'; beta,beta) > 0}.

iLBCT(alpha, beta)
  = #{(b1,b1') :
        DDT(b1,beta) > 0,
        DDT(b1',beta) > 0,
        GBCT(alpha,alpha; b1,b1') > 0}.
```

计数对象是有序对；但本题只需完整判定每个表项是否为零。

## 应检查的恒等性质

令 `iUBCT_S` 和 `iLBCT_S` 表示由 `S` 计算的表。应检查：

```text
iUBCT_S(0,beta) = 1,
iLBCT_S(alpha,0) = 1,
iUBCT_S(alpha,0) > 0,
iLBCT_S(0,beta) > 0,

iUBCT_S(alpha,beta) = iLBCT_{S^{-1}}(beta,alpha),
iLBCT_S(alpha,beta) = iUBCT_{S^{-1}}(beta,alpha).
```

## 规范编码与摘要

每个零集合由 `(alpha,beta)` 整数对组成。按 `alpha`、再按 `beta` 数值升序排列，每行写成两个恰好两位的小写十六进制数：

```text
aa,bb
```

不带 `0x`，使用 LF 换行，并在最后一行后保留换行。对这些 ASCII 字节计算 SHA-256。并集使用相同规则排序和编码。

机器可读产物可以使用 JSON、CSV 或上述规范文本，但必须无歧义地区分 iUBCT 零集合和 iLBCT 零集合。
