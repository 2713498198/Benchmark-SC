# 固定 PRESENT-80 密钥恢复实例

## 1. 分析边界

状态为 64 比特，状态位和轮密钥位均从最低有效位开始编号，位 0 位于十六进制表示的最右端。每轮依次执行轮密钥异或、16 个并行 4 比特 S-box 和位排列；最后另有白化轮密钥。

十四轮区分器为

```text
0700000000000700  --14 rounds-->  0000000900000009
```

其概率按 `2^-p` 记，固定 `p=62`。本题在区分器前接 `nrSBp=2` 轮、后接 `nrSBc=2` 轮，总计 18 轮。区分器本身的经验有效性不在本题范围内；本题只审计给定边界下的密钥恢复。

## 2. 实例文件

`present80_2plus2_instance.txt` 是唯一的机器输入，字段含义如下。

- `SB`：按输入 `0..15` 排列的 PRESENT S-box 真值表。
- `PERM`：`PERM[i]` 是位 `i` 经线性层后的目标位置。
- `nrSBp`、`nrSBc`、`nrR`：前接轮数、后接轮数和总轮数。
- `DINa`：进入区分器前最后一次 S-box 层的输出差分约束。
- `DINb`：同一 S-box 层输入端的附加差分约束。
- `DOUTb`：离开区分器后第一次 S-box 层的输入差分约束。
- `DOUTa`：同一 S-box 层输出端的附加差分约束。
- `DKEY`：各轮密钥差分；本题均为零，即单密钥模型。
- `KS` 后每行是一条右端为零的 GF(2) 线性方程，例如 `k1[0] + k0[19]` 表示两位相等。本实例用可逆线性关系替代真实 PRESENT-80 密钥调度中的 4 比特非线性更新；结论必须明确这一模型边界。

差分约束中的 `0`、`1` 和 `3` 分别表示固定零、固定一和未指定。内部计算时可将 `3` 规范化为通配符 `*`。

## 3. 确定性差分传播

先从 `SB` 枚举得到 DDT。对一个含通配符的 S-box 输入模式，枚举其全部具体输入差分及所有 DDT 非零输出：某输出位若始终为 0 则传播为 0，始终为 1 则传播为 1，否则为 `*`。逆向传播同理，通过所有与给定输出模式 DDT 兼容的输入差分求公共位。轮间按 `PERM` 或其逆排列传递，并异或 `DKEY`。

传播到最外侧后，输入差分空间 `Din` 和输出差分空间 `Dout` 的维数分别记为 `din` 和 `dout`。进入在线密钥恢复的候选对数量为

```text
log2(N) = p + din - 64 + dout.
```

## 4. 活动 S-box 与预筛选

前接和后接轮中输入差分模式非零的 S-box 都必须被策略覆盖。对每个外接 S-box，直接枚举有序输入对 `(x,x')`，保留同时满足其输入和输出差分模式的项。

预筛选键由在线阶段可见的信息组成：有未知轮密钥值的输入位只存差分；由 `KS` 方程确定、不需要猜测的位存两边的实际值。设去重后筛选键数量为 `L`、键空间维数为 `e`，该 S-box 的通过率为 `L/2^e`。相容筛选可组合，进入后续求解的数据对指数应扣除相应的 `-log2(L/2^e)`。

## 5. 策略和成本模型

一个策略是由基本 S-box 求解器组成的二叉合并树。每个策略节点至少应记录：已覆盖的前向/后向 S-box、是否依赖在线数据对、估计解数量指数、在线时间指数、离线时间指数和内存指数。可用任意字段名和序列化格式，只要这些信息足以重放。

合并两个子策略时，覆盖集合取并集；重复状态变量只计一次，轮密钥自由度由 `KS` 在线性子空间上的 GF(2) 秩扣除。若两个子策略都在线，则

```text
log2(Ton) = max(log2(Ton_left), log2(Ton_right), log2(Sol_merged)).
```

若仅一个子策略在线，则在线时间是该在线子策略时间与合并后解数量的最大值；两个都离线时在线时间为零。离线时间取子树及合并枚举的最大值。内存至少覆盖待哈希的较小一侧；若一侧在线、一侧离线，则需容纳离线侧解表。

同一个活动 S-box可以先只执行筛选、稍后再枚举其完整值，但最终策略必须覆盖所有活动 S-box 的完整求解义务。允许顺序求解、并行分支、预计算或任何等价合并顺序。

平均每个初始候选对的在线成本记为 `CKR`。任何完整在线密钥恢复至少需要扫描一次全部 `N` 个初始候选对，因此 `CKR >= 1`。若给出的可复放策略达到 `CKR=1`，该值即由上下界相合证明为模型内最优。十八轮密钥恢复有效性的判据是

```text
log2(N * CKR) < 80.
```
