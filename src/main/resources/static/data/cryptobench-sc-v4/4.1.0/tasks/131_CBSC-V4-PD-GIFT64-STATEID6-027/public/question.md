# GIFT-64 六轮固定边界状态传播审计

附件 `attachments/gift64_state_id_instance.json` 完整定义了一个 GIFT-64 六轮实例。对固定输入差分

```text
0x0000000000000600
```

和固定输出差分

```text
0x0000004020000110
```

进行严格审计：判定该边界在普通逐 S-box DDT 差分传播模型中能否由一条六轮 trail 连接，同时判定是否存在一对输入状态和一个共享的 128 位主密钥，使两次真实六轮执行产生该输出差分。依据两个判定说明它是否构成附件定义下的单密钥不可能差分，并解释两个模型的结论为何可能不同。

返回可直接执行的建模、求解与结果复放代码。若某个模型可满足，给出可独立复放的 witness；若不可满足，保留完备求解器的 `UNSAT` 或等价不可行证据。不要把 `UNKNOWN`、`TIME_LIMIT` 或“没有找到解”写成不可满足证明。

环境提供 Python、Z3、PySAT、CaDiCaL 和 CryptoMiniSat，也允许使用其他能返回完备状态的求解方法。
