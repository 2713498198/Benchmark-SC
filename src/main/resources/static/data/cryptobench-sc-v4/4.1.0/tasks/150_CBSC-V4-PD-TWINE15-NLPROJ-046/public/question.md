# TWINE 十五轮固定差分 trail 的非线性子密钥投影审计

附件 `attachments/twine15_constraint_spec.md` 完整定义了本题采用的 TWINE S-box、轮方程、变量编号和 15 轮固定差分 trail；`attachments/reference_paper.pdf` 仅提供研究背景，若表述存在差异，以形式化附件为准。

在附件规定的独立轮子密钥模型下，验证该 trail 的局部 Markov 权重。然后考察包含

```text
y^11_12 = S(x^11_12)
```

的最小连通非线性约束子集。由轮方程导出该子集，消去其中不受差分直接约束的中间状态，并精确分析它在四元组

```text
(k^9_0, k^10_4, k^11_6, k^12_5)
```

上的投影关系。对全部 `16^4` 个四元组，报告可行四元组总数、不可行总数、每个四元组所对应内部 S-box 输入见证数的完整重数分布，以及所有见证总数。

这里的见证重数明确指：消元后约束系统中满足关系的**不同 `x^11_12` 取值数**。直接值域中的多个变量组合若产生相同的消元 XOR 值，只按该 XOR 集合中的一个值处理，不重复增加见证数。完整可行投影及上述重数应作为机器可读产物保存，无须在最终报告中逐行展开。

必须返回可直接执行的验证代码、机器可读结果和简洁结论。结论应区分本题所分析的单个约束子集与完整 15 轮 trail；不得把该投影比例直接表述为标准 TWINE 主密钥空间比例或完整 trail 的条件概率。
