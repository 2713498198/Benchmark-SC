# Serpent 三轮差分线性中部的精确加权 ANF 偏差审计

附件 `attachments/serpent_datf_instance.json` 给出一个 Serpent 差分线性中部的固定代数实例。该实例对应 bitslice 状态编号下的三轮中部：S 盒起始偏移为 2，输入差分位集合为 `{78}`，输出线性掩码位集合为 `{61,64}`。为控制代数表达式规模，输入位 `110、14、46` 被分区；`assignment` 的第 0、1、2 个二进制位依次给出这三个输入位的取值。

每个 `case` 都定义一个独立的布尔函数 `F`：

- `anf_monomials` 是 `F` 的 ANF。列表中的各单项式按 XOR 相加，单项式内部变量按 AND 相乘，空单项式表示常数 1。
- `variables[name].p0` 和 `p1` 分别是该变量取 0 和 1 的精确概率；同一 `case` 中列出的变量相互独立。
- 不同 `case` 是分区后的八个条件空间，不共享随机变量。
- 单个条件空间的有符号偏差定义为 `epsilon_c = Pr[F=0] - 1/2`；总偏差是八个 `epsilon_c` 的算术平均值。

请精确计算 `assignment=0,...,7` 的八个有符号偏差以及总偏差。结果必须给出最简分数、十进制近似和 `log2(abs(total_bias))`，并明确总偏差的符号。对每个条件空间，请保留足以复核精确计数的证据，例如非均匀变量各分支的真值表计数，或等价的精确 BDD、Shannon 分解、SAT/model-count 证书。

返回可直接执行的代码、包含全部八个条件空间结果的机器可读文件，以及说明 ANF、变量概率、分区平均和精确性边界的最终报告。随机抽样只能作为交叉检查，不能替代精确结果。
