# PRESENT S-box 完整 L 类 division-trail 关系审计

考虑 PRESENT 的 4 比特 S-box

```text
S = [c,5,6,b,9,0,a,d,3,e,f,8,4,7,1,2].
```

输入和输出掩码均写成 `0..15` 的整数；第 `j` 位对应变量 `x_j`。对输出掩码 `u`，令

```text
P_u(x) = product(S(x) 的第 j 个输出比特, 对所有满足 u_j=1 的 j)
```

并令 `A_u` 为 `P_u` 的代数正规形中系数为 1 的全部输入单项式掩码集合。乘积为空时取 1。

本题采用以下完整 L 类传播定义：`(0,0)` 和 `(15,15)` 是有效边界传播；对于 `1 <= ell <= 14`、`1 <= u <= 15`，`ell -> u` 有效，当且仅当 `ell` 属于 `A_u`，且存在 `k in {0,...,15}`，使得对每个 `a in A_u` 都有 `(k & a) != k`。除此之外的掩码对均无效。

请编写可直接执行的程序，重建全部 `A_u` 并穷举完整的有效传播关系。随后审计以下两条旧规则；两者同样只额外包含边界传播 `(0,0)` 和 `(15,15)`，内部范围仍为 `1 <= ell <= 14`、`1 <= u <= 15`：

- `L1`：`ell` 属于 `A_u`，且 `A_u` 中不存在严格包含 `ell` 的单项式掩码；
- `L2`：只要求 `ell` 属于 `A_u`。

报告完整关系、`L1` 和 `L2` 各自的传播对数，以及两条旧规则相对完整关系的全部漏报与误报。至少为一个 `L1` 漏报给出满足完整判据的 `k`，并为一个 `L2` 误报说明为什么不存在这样的 `k`。返回可执行代码、机器可读审计结果和最终报告。
