# Question 112. GIFT-128 18 轮固定差分特征有效性验证

附件 `attachments/gift128_spec.json` 给出了本题采用的 GIFT-128 S-box、位编号、置换方向、部分密钥加法位置和轮常数的放宽处理；`attachments/trail_18r.txt` 依次给出 18 轮 S-box 层的输入差分与输出差分，每个 32 位十六进制串的最右侧 nibble 编号为 0。

请实现一个 SAT/SMT 或等价的精确值约束验证器，判断是否存在任意明文对和轮密钥赋值，使附件中的全部 S-box 差分转移和线性层连接同时成立。为避免密钥编排和固定常数造成额外限制，本题把每轮注入位置上的密钥比特以及规范列出的轮常数比特视为相互独立的自由变量；其他位置没有密钥或常数注入。因此在该放宽模型下证明不可满足，就足以否定原差分特征。

若模型不可满足，请定位一个不可再缩的冲突 S-box 集合，并给出由具体 S-box 输入/输出值集合导出的局部矛盾。轮和 S-box 均从 0 开始编号。返回可执行代码、求解状态、冲突位置和可复核的求解证据。
