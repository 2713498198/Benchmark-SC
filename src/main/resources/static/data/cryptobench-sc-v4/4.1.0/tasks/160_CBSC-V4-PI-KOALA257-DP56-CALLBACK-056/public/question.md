# Koala 257 位模型的五/六轮积分工具审计

附件 `attachments/koala_dp_audit_spec.md` 给出了一个 257 位变换的 bit-based two-subset division-property 模型，以及一段声称在五轮找到积分区分器的求解器回调和运行摘要。

请审计该结论是否由运行摘要正确推出，并在完全相同的模型下分别计算五轮和六轮可达的全部单位输出向量集合。报告每轮的可达坐标、模型能够保证平衡的输出坐标及其数量，并按附件规则给出规范化摘要。必须说明原回调是否可靠、如何修正或绕开它，以及修正后结论的适用边界。

请留下可直接执行的建模/验证代码、机器可读结果和简洁报告。可自由使用 MILP、SAT/SMT 或其他精确方法；若使用宿主 Gurobi，可将 LP/MPS 模型交给工作区中的 `cbsc_gurobi_solve.py`，具体命令见附件。
