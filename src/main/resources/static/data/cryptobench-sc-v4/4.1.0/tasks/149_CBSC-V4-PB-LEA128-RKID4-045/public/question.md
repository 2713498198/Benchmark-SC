# LEA-128 四轮相关密钥不可能差分判定

附件 `attachments/lea128_4round_spec.md` 完整定义了本题使用的 LEA-128 轮函数、密钥扩展、字序和测试向量；`attachments/reference_paper.pdf` 仅作为来源背景，若表述存在差异，以形式化规范为准。

设两次加密使用相同明文 `P'=P`，主密钥满足

```text
K' xor K = (0x00000001, 0x00000000, 0x00000000, 0x00000000).
```

判断执行恰好 4 轮后，是否存在 `P` 与 `K` 使

```text
E_K^4(P) xor E_K'^4(P') =
(0x00000000, 0x00000000, 0x00000000, 0x00000000).
```

若存在，请给出可复核的明文和主密钥见证；若不存在，请给出精确的不可满足性证明。必须返回可直接执行的验证代码、机器可读结果和简洁结论，并说明代码如何同时约束两次密钥扩展和两次加密。随机抽样或只检查有限组密钥不能证明“不可能”。
