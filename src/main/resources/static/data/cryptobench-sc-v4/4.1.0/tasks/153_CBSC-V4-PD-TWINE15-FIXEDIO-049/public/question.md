# TWINE 十五轮固定边界最优差分特征搜索

附件 `attachments/twine15_fixed_io_spec.md` 完整定义了本题采用的 TWINE 轮函数、差分权重、nibble 编号、固定输入输出边界以及最后一轮约定。

在这些固定边界下，求十五轮单条差分特征的最小总权重。返回一条完整、逐轮相连的最优特征，列出每轮 S-box 输入差分、S-box 输出差分、局部 DDT 计数或等价权重、每轮权重和总概率，并提供足以证明不存在更低权重特征的可核验证据。

必须返回可直接执行的建模或验证代码、机器可读结果和简洁结论。环境中如出现 `cbsc_gurobi_solve.py`，可先运行 `python3 cbsc_gurobi_solve.py --help`，再将生成的 LP/MPS 模型交给沙箱外的许可 Gurobi；也可使用 SAT、SMT、动态规划或其他精确方法。仅给出一个权重数值、未连接的逐轮局部转移或没有最优性证据的可行特征，不构成完整答案。
