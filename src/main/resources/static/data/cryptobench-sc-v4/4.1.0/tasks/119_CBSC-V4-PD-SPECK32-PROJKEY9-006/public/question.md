# Question 119. SPECK-32 九轮固定差分特征的轮密钥条件投影

附件 `attachments/speck32_longkey_spec.json` 给出本题使用的 SPECK-32 长密钥轮函数与比特编号，`attachments/trail_9r.json` 给出九轮各边界的左右字差分。九个 16 比特轮密钥彼此独立，但同一轮密钥同时用于一对执行。

请建立精确的 SAT、SMT 或等价位级模型，判断哪些轮密钥能够使附件中的完整差分特征存在至少一对具体状态值。随后对以下六个轮密钥比特作存在量词投影，其他状态比特和轮密钥比特均保持自由：

[
v=(RK_1[13],RK_1[14],RK_3[8],RK_3[9],RK_4[2],RK_4[3]).
]

求出这 6 比特投影的精确可行集合，并将其化为简洁的布尔条件；同时报告 64 个赋值中可行赋值的数量与比例，以及该 trail 按模加差分转移独立相乘得到的 DDT 概率。返回可执行代码和可复核的逐赋值 SAT/UNSAT 或等价精确证据。
