# SIMON-32 十一轮固定边界的零相关判定

考虑 SIMON-32 的 11 轮轮函数核心。状态由两个 16 位字 `(L_r, R_r)` 组成，比特从最低位开始编号为 `0,...,15`，所有下标均模 16。本文采用如下明确的旋转约定：`ROL_j(X)` 的输出比特 `i` 等于 `X[(i+j) mod 16]`。一轮定义为

```text
R_{r+1} = L_r,
L_{r+1} = R_r xor (ROL_1(L_r) & ROL_8(L_r)) xor ROL_2(L_r) xor K_r,
```

其中 `K_r` 是任意固定轮密钥；它只可能改变线性特征的符号，不改变非零相关线性 trail 的支持集。

固定输入线性掩码和输出线性掩码为

```text
输入（r = 0）：  (L_0,  R_0)  = (0x8000, 0x0000)
输出（r = 11）： (L_11, R_11) = (0x0000, 0x0100)
```

请判断这对掩码在 11 轮 SIMON-32 上是否对任意固定轮密钥都构成零相关线性逼近。返回可直接执行的精确验证代码和可核查的证明证据，并说明你的模型如何处理 XOR、分支、旋转和一比特 AND 门的非零 LAT 支持，以及求解状态如何推出最终结论。

为校验模型没有退化为恒定输出不可满足，请用完全相同的方法同时检查相邻对照边界

```text
输入（r = 0）：  (L_0,  R_0)  = (0x8000, 0x0000)
输出（r = 11）： (L_11, R_11) = (0x0000, 0x0080)
```

并在对照边界可满足时给出一条完整的逐轮掩码 trail。允许使用 SAT/SMT、CP、BDD、精确符号传播或其他等价的完备方法；随机抽样不能替代精确判定。
