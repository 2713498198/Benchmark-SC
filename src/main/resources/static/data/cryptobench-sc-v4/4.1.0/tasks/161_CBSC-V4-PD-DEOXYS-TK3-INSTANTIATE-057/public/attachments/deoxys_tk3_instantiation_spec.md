# Deoxys-BC RTK3 差分实例化规范

## 1. 字节、有限域与 AES S-box

所有字节均解释为 `0..255` 的整数。有限域为

```text
F = GF(2)[X] / (X^8 + X^4 + X^3 + X + 1).
```

字节的最低位是常数项系数。`mul(a,b)`、除法和矩阵乘法均在该域中进行，向量加法为逐字节异或。

AES S-box 定义为 `S(0)=0x63`；当 `x != 0` 时先在 `F` 中求 `x^-1`，再按以下 LSB-first 公式计算每个输出位：

```text
S(x)[i] = x_inv[i] xor x_inv[(i+4) mod 8] xor x_inv[(i+5) mod 8]
          xor x_inv[(i+6) mod 8] xor x_inv[(i+7) mod 8] xor 0x63[i].
```

定义

```text
DDT[a,b] = |{x : S(x) xor S(x xor a) = b}|,

BCT[a,b] = |{x : S^-1(S(x) xor b) xor
                  S^-1(S(x xor a) xor b) = a}|.
```

## 2. 线性层与 tweakey LFSR

AES MixColumns 矩阵及其逆矩阵为

```text
MC = [[02,03,01,01],       IMC = [[0e,0b,0d,09],
      [01,02,03,01],              [09,0e,0b,0d],
      [01,01,02,03],              [0d,09,0e,0b],
      [03,01,01,02]]              [0b,0d,09,0e]].
```

对一个字节 `x`，定义

```text
L2(x) = ((x << 1) & 0xfe) xor ((x >> 7) & 1) xor ((x >> 5) & 1),
L3(x) = (x >> 1) xor ((((x & 1) xor ((x >> 6) & 1))) << 7).
```

`L3` 是 `L2` 的逆。对三字节 `(t1,t2,t3)`，第 `r` 轮的组合差分为

```text
K_r(t1,t2,t3) = t1 xor L2^r(t2) xor L3^r(t3).
```

## 3. 上部 tweakey 差分集合

上部有四个活动基位置，顺序固定为

```text
P_U = [0, 5, 10, 15].
```

每个位置 `p` 对应三字节 `U[p]=(u1,u2,u3)`。合法上部差分满足：

```text
K_2(U[p]) = 0 and K_3(U[p]) = 0,  for every p in P_U,

IMC * [K_1(U[5]), K_1(U[10]), K_1(U[15]), K_1(U[0])]^T
     = [free, 0, 0, 0]^T,

U != 0.
```

定义三个 BCT 第一参数：

```text
A = [K_5(U[10]), K_5(U[15]), K_5(U[0])].
```

## 4. 下部 tweakey 差分集合与 DDT 筛选

下部活动基位置的固定顺序为

```text
P_L = [2, 5, 15].
```

每个位置 `p` 对应三字节 `L[p]=(l1,l2,l3)`。合法下部差分满足：

```text
K_8(L[p]) = 0 and K_9(L[p]) = 0,  for every p in P_L,

IMC * [K_7(L[15]), 0, K_7(L[5]), K_7(L[2])]^T
     = [*, 0, *, *]^T,

L != 0.
```

然后计算：

```text
k6_3 = K_6(L[5]),
x6_2 = (0x0b / 0x0e) * k6_3,
y5_15 = (IMC * [0, 0, x6_2, k6_3]^T)[3],

k6_4 = K_6(L[2]),
x6_7 = (0x09 / 0x0d) * k6_4,
y5_14 = (IMC * [k6_4, 0, 0, x6_7]^T)[2],

k6_9 = K_6(L[15]),
x6_8 = (0x0b / 0x0e) * k6_9,
y5_13 = (IMC * [x6_8, k6_9, 0, 0]^T)[1].
```

再令

```text
[y6_8, unused, y6_2, y6_7]^T
    = IMC * [K_7(L[15]), 0, K_7(L[5]), K_7(L[2])]^T,

D = DDT[x6_8,y6_8] * DDT[x6_7,y6_7] * DDT[x6_2,y6_2].
```

只保留 `D != 0` 的下部差分，并定义

```text
B = [y5_13, y5_14, y5_15].
```

## 5. 优化目标与输出口径

对每个合法候选对 `(U,L)`，精确计算

```text
V(U,L) = BCT[A[0],B[0]] * BCT[A[1],B[1]] * BCT[A[2],B[2]] * D^2.
```

必须报告：

1. 上部线性核包含零向量时的规模，以及排除零向量后的上候选数；
2. 下部线性核包含零向量时的规模，以及排除零向量并通过 `D != 0` 后的候选数；
3. 实际评价的 `(U,L)` 候选对数量；
4. `max V` 及达到该值的候选对数量；
5. 规范 witness 及其 `A`、`B`、三个 BCT 因子、三个 DDT 因子和 `D`。

把 `U` 按基位置 `[0,5,10,15]`、每个位置按 `(t1,t2,t3)` 展平为 12 个字节；把 `L` 按基位置 `[2,5,15]` 同样展平为 9 个字节。所有最大值 witness 按 `(U 的 12 字节, L 的 9 字节)` 的无符号字节字典序排序，最小者定义为规范 witness。

规范摘要只包含

```json
{"maximum_score": INTEGER, "upper_bytes": [LOWERCASE_TWO_DIGIT_HEX...], "lower_bytes": [LOWERCASE_TWO_DIGIT_HEX...]}
```

使用键排序、无多余空白的 UTF-8 JSON 字节计算 SHA-256，并一并报告摘要散列。
