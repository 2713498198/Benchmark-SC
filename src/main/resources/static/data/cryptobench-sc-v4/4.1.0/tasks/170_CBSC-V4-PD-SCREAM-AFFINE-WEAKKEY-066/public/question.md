# Scream 仿射自等价弱密钥与任意轮截断差分

考虑零 tweak 下的 128 位 tweakable block cipher Scream。状态由 16 个 8 位列组成；对字节 `x`，按列向量

```text
(x7,x6,x5,x4,x3,x2,x1,x0)^T,  x = sum_{i=0}^7 xi*2^i
```

解释其比特。每轮对 16 列并行应用同一个 8 位 S-box，随后把轮常数异或到最低有效位行，再对 8 个 16 位行分别应用同一个二进制 L-box。每两个这样的轮构成一步，并在每步前后异或 128 位 tweakey；本题 tweak 为零，因此所有 tweakey 都等于主密钥 `K`。轮常数是最低有效位行上的任意公开 16 位值，等价地，每个状态列上异或 `0x00` 或 `0x01`。

请找出一个非恒等 8 位仿射双射 `A(x)=M*x xor c`，使其逐列提升到 128 位状态后，可在一个非平凡主密钥子空间上与任意轮数的上述 Scream 计算交换。给出 `M`、`c`、主密钥子空间的完整线性描述及其维数和大小，并令

```text
U_A = {x xor A(x) : x in {0,1}^8}.
```

由该交换关系导出轮数无关的截断差分时，采用下面固定的概率实验：先任取并固定一个 `alpha in U_A^16`，再均匀随机选择 128 位 `X`，输入明文对为 `(X, X xor alpha)`。请计算该输入对恰好等于仿射配对 `(X,A(X))` 的精确概率，并说明在此事件发生时任意轮后的输出差分集合。这个概率给出该截断差分中由交换路径保证的概率贡献；不要把实验改成直接选择 `(X,A(X))`，后者是条件化构造且其交换成功概率为 1。还需给出每轮活动 S-box 的结论。

返回能够自动搜索或完整验证这些结论的可直接执行代码及实际运行结果。有限随机抽样、只引用一个结论或仅打印预置常数，不构成完整验证。
