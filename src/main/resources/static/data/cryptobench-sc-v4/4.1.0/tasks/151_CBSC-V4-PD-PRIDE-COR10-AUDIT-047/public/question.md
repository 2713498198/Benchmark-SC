# PRIDE 两轮概率一差分候选的局部兼容性审计

附件 `attachments/pride_local_compatibility_spec.md` 完整定义了本题的 S-box、两个局部线性映射、位序和待验证等式；`attachments/reference_paper.pdf` 仅提供研究背景，若表述存在差异，以形式化附件为准。

对附件定义的全部候选四元组 `(M, kappa, alpha, beta)` 进行精确审计。对每个候选，计算兼容等式在 16 个输入中成立的数量，并保存对应输入集合的 16 位位图。汇总满足数量的完整直方图、最大满足数量及达到该最大值的候选数，并判断是否存在对全部 16 个输入均成立的候选。

必须返回可直接执行的验证代码、包含全部候选逐项结果的机器可读产物和简洁结论。结论必须限定在附件给出的局部必要兼容条件上，不得把部分输入成立解释为概率一差分存在。
