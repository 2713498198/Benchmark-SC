# 3 比特密钥化置换的正向/逆向积分抗性审计

附件 `attachments/keyed_permutations.csv` 给出一个 5 比特密钥索引的 3 比特置换族，`attachments/integral_resistance_model.md` 给出位序、ANF 系数和广义一阶积分抗性的判定规则。

请实现一个可执行程序，分别审计该置换族的正向映射和逐密钥逆映射。程序需要从表格本身重建各坐标函数的 ANF 系数函数，计算判定所需的 GF(2) 秩与零空间，并判断正向和逆向是否具有广义一阶积分抗性。如果任一方向不满足该性质，必须给出一个非零的系数函数线性依赖，并将其转换成可直接在全部 32 个密钥上复放的积分见证。

返回可执行代码、机器可读审计证据和简洁结论。只报告“正向成立、逆向不成立”而不给出秩、依赖关系和逐密钥见证，不构成完整答案。
