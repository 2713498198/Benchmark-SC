# 16 位模加置换的 boomerang 表分区审计

附件 `attachments/modadd_boomerang_tables_spec.md` 定义了一个 16 位模加置换及其 BCT、UBCT、LBCT 和 EBCT 计数。

对附件给定的固定差分，精确计算 BCT 条目及其概率，并分别枚举附加左差分参数的全部 `2^16` 个取值，得到完整 UBCT 分区和完整 LBCT 分区。报告两个分区的非零分支、非零分支数、计数和、最大计数及全部最大值参数。若某个分区的非零分支较多，可在报告中概括，但必须留下包含全部非零分支及精确计数的机器可读产物。

再取两个分区中按无符号整数排序最小的最大值参数，计算对应 EBCT 条目，并分别对 EBCT 的两个附加参数求和，核验它与 UBCT、LBCT 分区的边际一致性。

必须返回可直接执行的精确分析代码、机器可读结果和简洁审计报告。随机抽样、浮点近似或无法证明分区完整性的局部枚举不构成完整答案。
