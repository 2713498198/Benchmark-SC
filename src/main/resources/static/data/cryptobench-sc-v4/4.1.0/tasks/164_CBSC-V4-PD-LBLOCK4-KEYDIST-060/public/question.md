# LBlock 四轮固定差分 trail 的轮密钥依赖概率审计

附件 `attachments/lblock4_tl1_instance.json` 完整定义了 LBlock 的 nibble 轮函数、四轮固定差分 trail、独立轮密钥模型以及概率空间。

对所有四组独立的 32-bit 轮密钥，精确确定该固定 trail 的条件概率分布。报告局部 DDT 的 Markov 估计、实际出现的全部概率值及各自所占轮密钥比例，并给出一个足以解释该分布的最小轮子密钥投影或等价依赖关系。输出该投影全部等价类的机器可读结果。

请返回可直接执行的完整验证代码、运行结果和简洁结论。最终分布必须由穷尽枚举、变量消元、SAT/SMT、BDD 或其他完备方法得到；随机采样只能作为旁证，不能作为精确比例的证明。
