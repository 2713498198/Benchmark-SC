# Question 124. AES 固定四阶段差分线性相关精确计算

附件 `attachments/aes4r_dl_spec.json` 给出了 AES S-box、有限域、状态顺序、ShiftRows、MixColumns 和本题固定的差分线性计算对象。

对附件定义的随机实验，精确计算有符号相关

```text
C = E[(-1)^b * accept]
```

其中 `accept` 表示首轮输出差分恰为仅 `x[3][2]=d` 非零的指定形状，`b` 是随后三个独立 S-box 差分阶段在掩码 `0x09` 下的奇偶值。计算必须聚合全部可能的中间差分，不能只选择概率最高的单条差分特征，也不能把整数连接表漏归一化后直接当作相关。

请返回可执行代码、`C` 的约分精确值与符号、十进制值、`-log2(|C|)`，并保留足以复核聚合的非零首轮分支及其整数计数。结论只适用于附件定义的固定四阶段 Markov/generalized-DLCT 计算对象。
