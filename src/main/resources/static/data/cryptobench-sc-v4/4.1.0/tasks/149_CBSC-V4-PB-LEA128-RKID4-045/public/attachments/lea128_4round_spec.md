# LEA-128 四轮形式化规范

所有字均为 32 位无符号位向量。`+` 表示模 `2^32` 加法，`xor` 表示逐位异或；`ROL_r`、`ROR_r` 分别表示 32 位循环左移和循环右移，移位量按 32 取模。四字元组始终按 `(word0, word1, word2, word3)` 排列。

## 主密钥与常量

主密钥为 `(T0,T1,T2,T3)`。常量为：

```text
delta[0] = 0xc3efe9db
delta[1] = 0x44626b02
delta[2] = 0x79e27c8a
delta[3] = 0x78df30ec
```

## 第 i 轮密钥扩展

轮编号从 `i=0` 开始。每轮先原地更新：

```text
T0 = ROL_1 (T0 + ROL_i     (delta[i mod 4]))
T1 = ROL_3 (T1 + ROL_(i+1) (delta[i mod 4]))
T2 = ROL_6 (T2 + ROL_(i+2) (delta[i mod 4]))
T3 = ROL_11(T3 + ROL_(i+3) (delta[i mod 4]))
```

随后第 `i` 轮使用六个轮密钥字：

```text
(ki,0, ki,1, ki,2, ki,3, ki,4, ki,5) = (T0, T1, T2, T1, T3, T1).
```

两把相关主密钥必须分别、完整地执行上述扩展；不得把主密钥差分直接当作每轮轮密钥差分。

## 第 i 轮加密

设轮输入为 `(x0,x1,x2,x3)`，先保存 `old_x0=x0`，然后并行按旧轮输入计算：

```text
y0 = ROL_9((x0 xor ki,0) + (x1 xor ki,1))
y1 = ROR_5((x1 xor ki,2) + (x2 xor ki,3))
y2 = ROR_3((x2 xor ki,4) + (x3 xor ki,5))
y3 = old_x0
```

下一轮状态为 `(y0,y1,y2,y3)`。本题不执行初始/最终白化，只执行编号 `0,1,2,3` 的四轮密钥扩展和四轮加密。

## XOR 差分与存在性语义

差分均为 XOR 差分。一个固定边界“可能”是指至少存在一组具体的 `P,K`，使第二次执行使用 `P'=P xor deltaP`、`K'=K xor deltaK`，并得到指定的 `deltaC`；“不可能”是指这个存在量化公式在完整 32 位语义下不可满足。

下列向量用于检查字序、常量、轮密钥复用和旋转方向。执行标准 24 轮应得到：

```text
K  = (0x3c2d1e0f, 0x78695a4b, 0xb4a59687, 0xf0e1d2c3)

```
