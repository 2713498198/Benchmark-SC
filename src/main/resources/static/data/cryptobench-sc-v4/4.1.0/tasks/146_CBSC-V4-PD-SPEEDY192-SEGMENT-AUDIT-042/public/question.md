# SPEEDY-192 四个连续非线性段的精确可满足性审计

附件 `attachments/speedy_segments.json` 给出 SPEEDY 的 6 比特 S 盒和四个固定差分段。状态写成 `32 x 6` 比特矩阵 `A[r][c]`，其中 `0 <= r < 32`、`0 <= c < 6`。附件中一个长度为 6 的整数数组 `words=[w0,...,w5]` 表示

```text
A[r][c] = (wc >> r) & 1,
row_value(A,r) = sum(A[r][c] << (5-c) for c=0,...,5).
```

`SB` 对 32 个 6 比特行分别应用附件中的 S 盒。`SC` 按下式移动具体值和 XOR 差分中的每一比特：

```text
SC(A)[r][c] = A[(r+c) mod 32][c].
```

每个固定段给出三个差分 `D0`、`D1`、`D2`。称该段**精确可满足**，当且仅当存在两个具体输入状态 `X` 与 `X' = X xor D0`，使得

```text
Y  = SC(SB(X)),    Y' = SC(SB(X')),
Z  = SC(SB(Y)),    Z' = SC(SB(Y')),
Y xor Y' = D1,
Z xor Z' = D2.
```

附件中的 `naive_local_weight` 只是在忽略两层 S 盒共享具体中间值时，由局部 DDT 计数得到的元数据，不能作为精确可满足性的证明。

请分别判定 `S1`、`S2`、`S3`、`S4` 为 `SAT` 或 `UNSAT`。对 `SAT` 段给出可复放的具体输入见证；对 `UNSAT` 段给出覆盖完整具体值空间的不可满足证据。返回可直接执行的验证代码、机器可读结果和简洁结论。随机抽样、仅检查局部 DDT 非零或求解超时均不能证明 `UNSAT`。
