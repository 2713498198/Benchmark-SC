# CryptoBench

面向密码分析智能体的可交互前端原型。当前以分组密码为核心，预留流密码、后量子密码及更多密码分析方向。

## 运行

需要 Node.js 20 或以上版本，无需安装生产依赖。

```powershell
cd D:\Benchmark-SC
node server.mjs
```

浏览器访问 http://127.0.0.1:4173 。保持终端运行，按 Ctrl+C 停止。也可以双击 `start.cmd`。

## 已实现的页面和交互

- 首页：测评方向、本地接口 / 云端 Agent 测试入口、测评集、榜单预览、PK 入口。
- 测评集：搜索、筛选、卡片 / 列表、任务条件、评分规则、版本与任务样例下载。
- 工具与文档：Agent 接入协议建议、本地部署配置下载、报告与复现说明。
- 测评：本地接口 / 云端 Agent 模式切换、四步向导、Agent / 模型配置（支持自定义模型标识）、预算与任务范围、完成 / 取消 / 失败 / 超时、报告导出。
- PK：模型或 Agent 选择、固定赛场条件、客观通过率、平局与双方成绩。
- 榜单：按条件筛选、复现配置、2–4 项对比、CSV 导出。
- 账号与工作台：登录 / 注册 / 找回密码界面、体验账号、连接管理、实验记录、私有报告同步与单独公开。
- 管理：管理员体验账号、JSON 测评集校验、预览、发布固定版本。
- 响应式布局、移动导航、键盘操作与减少动态效果支持。

## 原型边界

这是前端设计与交互交付。测评集与排行榜为明确标注的示例；执行采用浏览器模拟器，不会连接实际 Agent，不包含密码分析执行器、评分后端、真实云服务或身份认证。输入密码和访问凭证不持久化；已有 `.env` 文件不由前端读取，静态服务器禁止访问点文件。

演示账号、连接元信息、测评报告和自定义任务包保存在当前浏览器的 localStorage 中。切换浏览器或清除站点数据会移除这些记录。同步与公开均为本地状态演示，不会上传数据。不同演示账号共用当前浏览器的记录，因此不能用作真实账号隔离。

当前可部署完整前端网页。桌面安装包、离线 Agent 执行、正式模型调用、真实报告同步、服务端校验与正式入榜需要后续后端实现。接入文档提供建议协议，而非已上线 API。

## 项目结构

```text
index.html             页面入口
css/                   基础样式、页面样式、测评资源样式
js/app.js              路由、页面框架、浏览器状态
js/core.js             图标、转义、导出等共用功能
js/data.js             明确标注的示例数据

js/pages/resources.js  测评集、工具、下载与文档

js/pages/community.js  榜单、账号、工作台、管理

tests/check.mjs        递归 JavaScript 语法检查
```

## 验证

```powershell
node tests/check.mjs
node tests/smoke.mjs
```

浏览器验收需要 Playwright 以及 Chrome / Edge。可安装开发依赖 `npm install --no-save playwright`，或通过 `PLAYWRIGHT_MODULE` 指定 Playwright 的 `index.mjs` 绝对路径，通过 `CHROME_PATH` 指定浏览器。运行测试前请先执行 `node server.mjs`，测试默认访问 4173 端口；截图与结果保存在 `tests/artifacts/`。

## 设计取舍

参考 OpenCompass 的模块导航、测评集组织与双入口体验，参考 Aider 的通过率、费用和复现配置。针对密码分析任务，固定数据版本与预算，以验证器判定的任务通过率为主要比较指标；不使用主观投票，也不把不同密码类型混成一个总分。模型 PK 固定 Agent 模板与工具，Agent PK 记录各自的模型与工具条件。本地与云端共用规则，报告默认私有，主动同步后再单独决定是否公开。
